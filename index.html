ⓘ Cách dùng & mở khoá giọng Microsoft

Luyện tập: bấm ▶ ở câu nào để lặp vô hạn. Bấm câu khác để chuyển. Bấm lại để tắt.

Chọn & Gộp: tick vào ô vuông trái mỗi câu để chọn. Khi chọn ≥2 câu, nút "Gộp" sẽ sáng — bấm để nối chúng thành một câu.

Tách câu: bấm ✂ ở mỗi câu để mở hộp thoại tách. Click vào khoảng giữa các từ để chọn điểm tách. Hoặc dùng "Tự động tách" theo dấu câu.

Sóng âm: khi câu đã được tổng hợp (Microsoft Neural), sóng âm sẽ hiện bên dưới nội dung câu.

Tải tất cả MP3: bấm "⬇ Tải tất cả MP3" để tổng hợp và gộp toàn bộ câu thành 1 file MP3 duy nhất.

Hai chế độ:
• Giọng thiết bị (mặc định): dùng giọng có sẵn. Chạy ngay, không tải MP3.
• Microsoft Neural: chất lượng cao, tải MP3, âm lượng >100%. Cần Cloudflare Worker.

Tạo Worker: vào dash.cloudflare.com → Workers → Create → Deploy → Edit code → dán file worker.js → Deploy → copy link dán vào ô trên.
